/gallery

Opens your private web gallery with every upload: thumbnail, file size, date, plus buttons to open, copy the link, or delete.

Why the Discord upload limit exists — and how to get around it

Discord caps attachments at 10MB on a free account. Nitro Basic pushes that to 50MB, full Nitro to 500MB, and Server Boost level 2 or 3 lifts the per-server cap to 50MB or 100MB. If you are not paying, the cap bites the moment you try to send a screen recording, a game clip, or a modpack.

The workaround is to stop sending the file and start sending a link. ImageUploader stores your file on its own host and posts a direct URL back into the channel. Discord sees a short piece of text, so its attachment limit never applies. Anyone in the channel — Nitro or not, phone or desktop — clicks and gets the full-quality original, with no re-compression of your video.

Compared with dumping files on a generic file host, the bot never makes you leave Discord: no browser tab, no login, no ad wall, no seven-day expiry. Upload with /upload, find it again later with /gallery.

FAQ

How do I bypass Discord's upload limit?

Upload through a bot instead of the Discord client. Run /upload, attach your file, and ImageUploader hosts it and posts a direct link. Discord only carries the link, so the 10MB attachment cap never applies to the file.

Can I send big files on Discord without Nitro?

Yes. Nitro raises the cap, but it is not the only route. ImageUploader is free and turns any file into a shareable link, so members without Nitro can share large videos, archives, and images in any channel.

What is Discord's file size limit in 2026?

10MB free, 50MB on Nitro Basic, 500MB on Nitro. Server Boost level 2 gives 50MB and level 3 gives 100MB server-wide. ImageUploader sits on top of any tier by hosting the file outside Discord.

What file types can I upload?

Images, video, GIFs, audio, PDFs, and archives. Images and video get a thumbnail preview in /gallery; everything else gets a file icon plus a direct link.

How long are my files kept?

As long as storage allows. Files are evicted LRU — least recently accessed goes first when space runs low — so any file can be removed at any time. Treat links as long-lived, not as a backup; keep your own copy of anything important. You can also delete a file yourself in /gallery, which kills the link immediately.

Is ImageUploader free?

Yes — the bot, /upload, and /gallery are all free. No paywall, no extra account beyond your Discord login.
